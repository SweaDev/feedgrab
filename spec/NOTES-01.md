# NOTES-01 — implementation decisions log
- T01: Biome 2.6 formats Markdown; `**/*.md` is excluded in `biome.json` so formatting never shifts the spec line references — PLAN L28 forbids spec edits.
- T01: Installed majors: ai 7, zod 4, typescript 7, @biomejs/biome 2.6, happy-dom 21, @playwright/test 1.64. Peer ranges use `>=<major>`.
- T01: `tsconfig.json` adds `resolveJsonModule` (needed for the package.json import in T30) and `skipLibCheck` (third-party d.ts noise) — not listed in PLAN L154-158 but harmless.
- T05: happy-dom 21 disables JS evaluation, CSS and iframe loading by default (the `disable*` flags are deprecated), so `parseHtml` only sets `disableJavaScriptFileLoading`, `disableComputedStyleRendering` and the user agent. `doc.write(html)` keeps `doc.URL === url`.
- T05: Capability probe (happy-dom 21): `:scope >`, `:has()`, `createTreeWalker`, `compareDocumentPosition`, `MutationObserver` on `getWindow(doc)` and `createHTMLDocument` + `innerHTML` all work. **No native `document.evaluate`** → `parseHtml` registers the `xpath` package. Workaround: the engine must call `xpath.parse(expr).select({ node, isHtml: true })`, because plain `xpath.select` treats XHTML-namespaced elements as non-matching for name tests.
